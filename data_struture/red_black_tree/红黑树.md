# 红黑树

1. 本质是弱平衡的二叉搜索树

   ![image-20260504155753904](C:\Users\17849\AppData\Roaming\Typora\typora-user-images\image-20260504155753904.png)

2. 黑路同：从**任意节点**出发，到**所有虚拟空叶子 NIL**，每条路径上**黑色节点个数必须相等**，这个数就叫 **黑高 BH**。
   - 最短路径：整条路**全是黑节点**，路径高度 = **BH**
   - 最长路径：**红黑交替**排布，红黑红黑……路径高度 = **2 × BH**
   - 如果有一个孩子是黑色，那另一个必须是黑色，否则违反这个性质
3. 泛型模版：

```
template <typename T>
class rbnodebase

template <typename key_type>
class rbtree_node : public rbnodebase<rbtree_node<key_type>>
```

- rbnodebase为泛型，参数是子类rbtree_node
- rbtree_node也是泛型，key的类型是key_type

4. 指针和对象：

   - 必须用指针代表left,right,parent,方便修改指针指向，且初始为空指针nullptr，创建的时候再new；而不是一开始就捏造一个对象无法设置为空且难以修改

   - 传参应该这样，改变指针指向而不是传一个对象；树只能有一份不能值传递必须传引用或者指针

     ```
     rbtree_node<key_type> *x, rbtree<key_type>*T
     ```
